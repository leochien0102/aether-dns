## M4-09 包定义：由本仓库产出 aether-dns ipk（**冻结 2026-11-11**）

- **单一目标**：新增 `openwrt/Makefile`，把**预先交叉编译好的静态 musl 二进制**打成 OpenWrt 包，元数据满足 `dns-engine` 虚拟依赖。
- **分支**：`feat/m4.09-openwrt-package`
- **卡片版本**：以本卡冻结提交为准（见发卡入口提示）；本卡不记录自身提交号

> 本卡只做"包定义 + 单架构本地验证"。四矩阵 CI、apk(25.12)、SHA256SUMS 与 Release 属 M4-10。
> 前置：[M4-03](m4-03.md)（版本已是 `1.0.0`）。

## 背景与证据

- 本仓库没有受跟踪的 OpenWrt Makefile；历史配方在仓库外 `openwrt-actions/build/rockchip/package/aether-dns-local/Makefile`（源码固定快照，不跟随 main），不能作为唯一权威来源。
- 参照实现：[`aether-proxy/chinadns-ng/Makefile`](../../../aether-proxy/chinadns-ng/Makefile)——只打包上游预编译二进制，`PKG_SOURCE_URL` + `PKG_HASH`，`Build/Compile` 为空。本卡不用下载方式，改用 CI 产出的本地二进制（避免与发布资产互为前提）。
- 现网 ipk 命名实证：`aether-dns_2026.11.04-1_aarch64_generic.ipk`，即 `name_<PKG_VERSION>-<PKG_RELEASE>_arch.ipk`。
- **包版本写法与 aether-proxy 保持一致（所有者 2026-11-11 决定）**：`aether-proxy/Makefile:4-5` 为 `PKG_VERSION:=0.7.0`、`PKG_RELEASE:=1`，即包版本 = `PKG_VERSION-PKG_RELEASE`（`0.7.0-1`）；产品显示串另拼为 `0.7.0-r1`（`aether-proxy/Makefile:48` 的 sed）。
  因此本卡取 `PKG_VERSION:=1.0.0`、`PKG_RELEASE:=1` → **包版本 `1.0.0-1`**，构建产物 `aether-dns_1.0.0-1_<arch>.ipk`；`-V` 保持纯 `1.0.0`（M4-03 已定，符合[版本契约](../design/semver-contract-20261109.md)，不随包修订号变化）。
- 发布资产名由 channel 侧规范化，不是构建产物名：`aether-proxy/tools/channel/build.py:139` 对 ipk 用**原始文件名**、对 apk 用 `{name}-{version}_{arch}.apk`。所以 M4-10 的 apk 资产名为 `aether-dns-1.0.0-1_<arch>.apk`（带 arch 后缀），ipk 资产名即构建产物名。
- 早期需求里写的 `1.0.0-r1` 资产名以本条为准，改为 `1.0.0-1`。

## 允许改动

- 新增 `openwrt/Makefile`
- 新增 `openwrt/README.md`（说明二进制放置方式与本地验证命令）
- `.gitignore`（忽略 `openwrt/files/aether-dns` 与 `openwrt/build/` 等构建产物）
- `docs/tasks/m4.md`（索引）
- `reports/M4-09.md`

不改 `src/`、`tests/`、`Cargo.toml`/`Cargo.lock`、`.github/`（属 M4-10）、其他仓库。

## 做什么

1. Makefile 头部：`include $(TOPDIR)/rules.mk`；`PKG_NAME:=aether-dns`、`PKG_VERSION:=1.0.0`、`PKG_RELEASE:=1`（与 aether-proxy 同款写法，包版本 `1.0.0-1`）、`PKG_LICENSE:=GPL-3.0-or-later`、`PKG_MAINTAINER:=leochien0102 <leochien0102@users.noreply.github.com>`。
   **不要写 `PKG_LICENSE_FILES`**：本仓库尚无 `LICENSE` 文件，写了会让构建找不到文件。补 `LICENSE` 与 `Cargo.toml` 的 `license` 字段是另一刀，不在本卡。
2. 二进制来源：`openwrt/files/aether-dns`（CI 或本地放置，**不入库**）。`Build/Prepare` 拷贝为 `$(PKG_BUILD_DIR)/aether-dns`，`Build/Compile` 留空——**不在 SDK 内编 Rust**。
   本地验证允许放**占位文件**（例如 host 构建产物或最小 stub）：本卡的判定对象是包结构、元数据与安装行为，不是二进制内容；真实 aarch64 静态产物由 M4-10 的 CI 交叉编译提供。
3. 包元数据：`SECTION:=net`、`CATEGORY:=Network`、`PROVIDES:=dns-engine`、`DEFAULT_VARIANT:=1`、`DEPENDS:=@(aarch64||x86_64)`。
4. 安装：仅 `$(INSTALL_BIN) $(PKG_BUILD_DIR)/aether-dns $(1)/usr/bin/aether-dns`。不写 `/etc`、无 `postinst`/`prerm`、无 init 单元。
5. 静态二进制不做二次 strip（`RSTRIP:=:`），避免破坏已 strip 的产物。

## 不做什么

- 不在 SDK 内编译 Rust；不引入 cargo 依赖。
- 不做 apk（25.12）与四矩阵 CI（M4-10）。
- 不加 remote、不建 tag、不发布、不改 channel。
- 不新增 `LICENSE` 文件、不改 `Cargo.toml` 的许可证字段、不写 `PKG_LICENSE_FILES`（追加许可证文件属独立的一刀）。
- 不改 proxy 的 `DEPENDS`（那是 proxy 仓库的事）。

## 停点

- 需要联网下载 SDK、安装交叉工具链、安装 rustup 目标或运行容器 → 停下请示（本机现有条件：无 aarch64 musl std、无 rustup、无 docker）。
- 构建系统把包版本渲染成 `1.0.0-1` 之外的形式（例如自行追加 `-r1`）→ 停下汇报，与"资产名 `1.0.0-1`"冲突需所有者裁决。
- 发现必须在 SDK 内编译 Rust 才能继续 → 停下（与既定方案冲突）。

## 验收（命令 + 可判定结果）

1. 用本地 24.10.8 SDK（`/workspace/openwrt/sdk/openwrt-sdk-24.10.8-rockchip-armv8_gcc-13.3.0_musl.Linux-x86_64`，`target-aarch64_generic_musl`；SDK 是工具目录，不是仓库，允许在其中构建）把 `openwrt/` 作为 feed/包目录使用，`make package/aether-dns/compile` 成功，产出 `aether-dns_1.0.0-1_aarch64_generic.ipk`。
2. `tar -xOf <ipk> ./control` 显示：`Package: aether-dns`、`Version: 1.0.0-1`、`Architecture: aarch64_generic`、`Provides: dns-engine`、`Default-Variant: 1`。
3. `tar -xJf <ipk> -O ./data.tar.gz | tar -tz` 只含 `./usr/bin/aether-dns`（不得有 `/etc`、init、postinst）。
4. 包内 `./usr/bin/aether-dns` 存在且为可执行权限（安装段正确）。
   若放入的是**真实交叉编译产物**，同时断言 `file` 显示 "statically linked"、`readelf -d` 无 `NEEDED`。
   本机没有 aarch64 musl 的 Rust std（`rustlib` 只有 `x86_64-unknown-linux-gnu`）、无 rustup、无 docker，因此**静态性断言随 M4-10 的 CI 产物完成**，本卡不因无法本地交叉编译而阻塞；报告中必须写明这一条是"委托 M4-10 验证"，不得写成已通过。
5. 离线 root（`opkg -o <root> --offline-root`）：`opkg install <ipk>` 成功；`<root>/usr/bin/aether-dns -V` 输出 `aether-dns 1.0.0`；`opkg status aether-dns` 含 `Provides: dns-engine`；`opkg remove aether-dns` 后文件清除干净。
6. `git status --porcelain` 干净；`git diff --stat main...HEAD` 只含「允许改动」。
