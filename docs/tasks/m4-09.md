## M4-09 包定义：由本仓库产出 aether-dns ipk（**冻结 2026-11-11**）

- **单一目标**：新增 `openwrt/Makefile`，把**预先交叉编译好的静态 musl 二进制**打成 OpenWrt 包，元数据满足 `dns-engine` 虚拟依赖。
- **分支**：`feat/m4.09-openwrt-package`
- **卡片版本**：以本卡冻结提交为准（见发卡入口提示）；本卡不记录自身提交号

> 本卡只做"包定义 + 单架构本地验证"。四矩阵 CI、apk(25.12)、SHA256SUMS 与 Release 属 M4-10。
> 前置：[M4-03](m4-03.md)（版本已是 `1.0.0`）。

## 背景与证据

- 本仓库没有受跟踪的 OpenWrt Makefile；历史配方在仓库外 `openwrt-actions/build/rockchip/package/aether-dns-local/Makefile`（源码固定快照，不跟随 main），不能作为唯一权威来源。
- 参照实现：[`aether-proxy/chinadns-ng/Makefile`](../../../aether-proxy/chinadns-ng/Makefile)——只打包上游预编译二进制，`PKG_SOURCE_URL` + `PKG_HASH`，`Build/Compile` 为空。本卡不用下载方式，改用 CI 产出的本地二进制（避免与发布资产互为前提）。
- **实测命名（24.10.8 SDK，本卡已构建验证）**：产物 `aether-dns_1.0.0-r1_aarch64_generic.ipk`，control 内 `Version: 1.0.0-r1`。**该 SDK 把版本渲染成 `PKG_VERSION-rPKG_RELEASE`**，所以 `PKG_RELEASE:=1` 得到 `-r1`，与 `aether-proxy_0.6.3-r7_all.ipk`（对应 `PKG_RELEASE:=7`）同构。
  因此包版本与资产名就是 **`1.0.0-r1`**；`-V` 仍是纯 `1.0.0`（M4-03 已定，符合[版本契约](../design/semver-contract-20261109.md)，不随包修订号变化）。此前卡里"改为 `1.0.0-1`"的判断被实测推翻，作废。
- 发布资产名由 channel 规范化（`aether-proxy/tools/channel/build.py:139`）：ipk 用构建产物原名，apk 用 `{name}-{version}_{arch}.apk` → `aether-dns-1.0.0-r1_<arch>.apk`，与最初需求一致。
- **`Default-Variant` 只出现在 apk 元数据**：`include/package-dumpinfo.mk:29` 与 `include/package-pack.mk:358`（转成 `provider-priority:100`）。ipk 的 control 里没有这个字段属预期，不是缺陷；ipk 侧可验证的是 `Provides: dns-engine`。
- ipk 的 `postinst`/`prerm` **由构建系统自动生成**，内容固定为 `default_postinst`/`default_prerm` 的转发脚本（无 `lib/functions.sh` 时直接退出）。这不是包特有逻辑，无法也不应去掉；可去掉的是自写脚本、`/etc` 内容与 init 单元。
- **静态二进制不应带 libc 依赖，但 SDK 默认注入**：`include/package-defaults.mk:5` 的 `PKG_DEFAULT_DEPENDS = +libc`，实测 control 出现 `Depends: libc`。需清空该默认值。

## 允许改动

- 新增 `openwrt/Makefile`
- 新增 `openwrt/README.md`（说明二进制放置方式与本地验证命令）
- `.gitignore`（忽略 `openwrt/files/aether-dns` 与 `openwrt/build/` 等构建产物）
- `docs/tasks/m4.md`（索引）
- `reports/M4-09.md`

不改 `src/`、`tests/`、`Cargo.toml`/`Cargo.lock`、`.github/`（属 M4-10）、其他仓库。

## 做什么

1. Makefile 头部：`include $(TOPDIR)/rules.mk`；`PKG_NAME:=aether-dns`、`PKG_VERSION:=1.0.0`、`PKG_RELEASE:=1`（与 aether-proxy 同款写法，包版本 `1.0.0-1`）、`PKG_LICENSE:=GPL-3.0-or-later`、`PKG_MAINTAINER:=leochien0102 <leochien0102@users.noreply.github.com>`。
   **不要写 `PKG_LICENSE_FILES`**：本仓库尚无 `LICENSE` 文件，写了会让构建找不到文件。补 `LICENSE` 与 `Cargo.toml` 的 `license` 字段是另一刀，不在本卡。
2. 二进制来源：`openwrt/files/aether-dns`（CI 或本地放置，**不入库**）。`Build/Prepare` 拷贝为 `$(PKG_BUILD_DIR)/aether-dns`，`Build/Compile` 留空——**不在 SDK 内编 Rust**。
   本地验证允许放**占位文件**（例如 host 构建产物或最小 stub）：本卡的判定对象是包结构、元数据与安装行为，不是二进制内容；真实 aarch64 静态产物由 M4-10 的 CI 交叉编译提供。
3. 包元数据：`SECTION:=net`、`CATEGORY:=Network`、`PROVIDES:=dns-engine`、`DEFAULT_VARIANT:=1`（供 apk 元数据）、`DEPENDS:=@(aarch64||x86_64)`。
   在 `include $(INCLUDE_DIR)/package.mk` **之后**、`$(eval $(call BuildPackage,aether-dns))` **之前**加一行 `PKG_DEFAULT_DEPENDS:=`，清掉 SDK 默认注入的 `+libc`（`PKG_FIXUP_DEPENDS` 在使用点展开：`include/package-defaults.mk:8`、`package-pack.mk:140`、`package-dumpinfo.mk:24`）。
4. 安装：仅 `$(INSTALL_BIN) $(PKG_BUILD_DIR)/aether-dns $(1)/usr/bin/aether-dns`。不写 `/etc`、无 init 单元、不自写 postinst/prerm；构建系统生成的 `default_postinst`/`default_prerm` 转发脚本允许保留。
5. 静态二进制不做二次 strip（`RSTRIP:=:`），避免破坏已 strip 的产物。

## 不做什么

- 不在 SDK 内编译 Rust；不引入 cargo 依赖。
- 不做 apk（25.12）与四矩阵 CI（M4-10）。
- 不加 remote、不建 tag、不发布、不改 channel。
- 不新增 `LICENSE` 文件、不改 `Cargo.toml` 的许可证字段、不写 `PKG_LICENSE_FILES`（追加许可证文件属独立的一刀）。
- 不改 proxy 的 `DEPENDS`（那是 proxy 仓库的事）。

## 停点

- 需要联网下载 SDK、安装交叉工具链、安装 rustup 目标或运行容器 → 停下请示（本机现有条件：无 aarch64 musl std、无 rustup、无 docker）。
- 构建系统把包版本渲染成 `1.0.0-r1` 之外的形式（例如只给 `1.0.0-1`）→ 停下汇报。
- 清空 `PKG_DEFAULT_DEPENDS` 后 control 仍出现 `Depends: libc` → 停下汇报，不要用裁剪/替换二进制的方式绕过。
- 发现必须在 SDK 内编译 Rust 才能继续 → 停下（与既定方案冲突）。

## 验收（命令 + 可判定结果）

1. 用本地 24.10.8 SDK（`/workspace/openwrt/sdk/openwrt-sdk-24.10.8-rockchip-armv8_gcc-13.3.0_musl.Linux-x86_64`，`target-aarch64_generic_musl`；SDK 是工具目录，不是仓库，允许在其中构建）把 `openwrt/` 作为 feed/包目录使用，`make package/aether-dns/compile` 成功，产出 `aether-dns_1.0.0-r1_aarch64_generic.ipk`。
2. control 必须这样取（ipk 是 `control.tar.gz` + `data.tar.gz` 两层）：
   `tar -xzOf <ipk> ./control.tar.gz | tar -xzO ./control`
   期望含：`Package: aether-dns`、`Version: 1.0.0-r1`、`Architecture: aarch64_generic`、`Provides: dns-engine`、`License: GPL-3.0-or-later`；**不得出现 `Depends: libc`**（无 `Depends` 行或其中不含 `libc` 均可）；**不要期待 `Default-Variant`**（ipk 无此字段，属 apk 侧，由 M4-10 验证）。
3. 包内容：
   - `tar -tzf <ipk>` 只有 `./debian-binary`、`./control.tar.gz`、`./data.tar.gz`；
   - `tar -xzOf <ipk> ./data.tar.gz | tar -tz` 只含 `./usr/`、`./usr/bin/`、`./usr/bin/aether-dns`（不得有 `/etc`、init 单元）；
   - `control.tar.gz` 内的 `postinst`/`prerm` 必须只有 `default_postinst`/`default_prerm` 转发，报告中贴出这两个文件内容。
4. 包内 `./usr/bin/aether-dns` 存在且为可执行权限（安装段正确）。
   若放入的是**真实交叉编译产物**，同时断言 `file` 显示 "statically linked"、`readelf -d` 无 `NEEDED`。
   本机没有 aarch64 musl 的 Rust std（`rustlib` 只有 `x86_64-unknown-linux-gnu`）、无 rustup、无 docker，因此**静态性断言随 M4-10 的 CI 产物完成**，本卡不因无法本地交叉编译而阻塞；报告中必须写明这一条是"委托 M4-10 验证"，不得写成已通过。
5. 离线 root（`opkg -o <root> --offline-root`）：`opkg install <ipk>` 成功；`<root>/usr/bin/aether-dns -V` 输出 `aether-dns 1.0.0`；`opkg status aether-dns` 含 `Provides: dns-engine`；`opkg remove aether-dns` 后文件清除干净。
6. `git status --porcelain` 干净；`git diff --stat main...HEAD` 只含「允许改动」。
