## M4-03 独立 semver：版本迁移到 1.0.0（**冻结 2026-11-11**）

- **单一目标**：把产品版本从日期版本 `2026.11.04` 迁到 `1.0.0`，并让 `-V` 由 Cargo 包版本派生，使二进制、Cargo、测试、文档一致。
- **分支**：`feat/m4.03-semver-1.0.0`
- **卡片版本**：以本卡冻结提交为准（见发卡入口提示）；本卡不记录自身提交号

> 依据：[版本契约草案](../design/semver-contract-20261109.md)（所有者 2026-11-09 定为 `1.0.0`、proxy 只设下限 `>=1.0.0`）。
> 本卡是 [M4-09](m4-09.md) 的前置：打包自检要求 `-V` 恰为 `1.0.0`。

## 背景与证据

- `src/main.rs:42` 硬编码 `aether-dns 2026.11.04`；`Cargo.toml:3` 是 `0.1.0`；`tests/cli.rs:34` 断言硬编码串、`:36` 断言 `>= 2025.08.09`（照抄 chinadns-ng 的旧闸门）。三者已经互相漂移。
- 打包与发布（M4-09 / CI）要求 `-V` 输出 `aether-dns 1.0.0`，否则安装自检必然失败。

## 允许改动

- `Cargo.toml`、`Cargo.lock`（**仅** aether-dns 自身那一条版本）
- `src/main.rs`（banner 一行）
- `tests/cli.rs`（banner 断言改为派生式；最低版本断言改为本引擎下限；新增 crate 版本一致断言）
- `README.md`（当前状态段的版本表述）
- `docs/handoffs/session-handoff-20261109.md`（版本表三行：Cargo / `-V` / opkg）
- `docs/design/semver-contract-20261109.md`（状态行：DNS 侧已落地）
- `docs/tasks/m4.md`（M4-03 状态）
- `reports/M4-03.md`

不改：查询行为、配置、缓存、日志；不改 `openwrt/` 包配方（M4-09）；不改历史报告与 PLAN 里程碑段里的 `2026.11.04`；不碰 aether-proxy / channel。

## 做什么

1. `Cargo.toml` 的 `version = "1.0.0"`，`Cargo.lock` 中 `name = "aether-dns"` 的 `version` 同步为 `1.0.0`（其余依赖条目不动）。
2. `src/main.rs`：`println!("aether-dns {}", env!("CARGO_PKG_VERSION"));`
3. `tests/cli.rs`：
   - banner 第二字段断言 `== env!("CARGO_PKG_VERSION")`；
   - **同时**断言该字段 `== "1.0.0"`（首次迁移显式钉住目标，否则"自洽"可以自洽在错版本上）；
   - 旧的 `>= 2025.08.09` 比较改为 `>= 1.0.0`，保留"proxy `parse_version` 的格式与比较语义可接受"这一性质；
   - 保留 bad-format 用例（其中的日期样本只是格式样本，与产品版本无关）。
4. 文档：README 当前状态、交接版本表、semver 契约状态行、`m4.md` 的 M4-03 结论。

## 不做什么

- 不改包版本（ipk 的 `1.0.0-r1` 属 M4-09）。
- 不构建交叉产物、不部署、不 push、不加 remote。
- 不引入预发布后缀（必须纯 `x.y.z`）。

## 停点

- 发现除上述之外还有代码/测试硬编码当前产品版本 → 停下汇报，不自行扩大。
- 发现需要同时改包配方或 CI → 停下（属 M4-09 / M4-10）。

## 验收（命令 + 可判定结果）

1. `cargo test --test cli` 全过；`cargo run -- -V` 输出 `aether-dns 1.0.0`。
2. banner 第二字段既等于 crate 版本、又等于 `1.0.0`。
3. 变异两项（报告写清"改了什么/哪条红/如何恢复"）：
   - 把 `Cargo.toml` 版本临时改回 `0.1.0` → `== "1.0.0"` 断言必红；
   - 把 `src/main.rs` 改回硬编码旧串 → 派生断言必红。
4. `cargo fmt --all -- --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test --all`、`bash tests/review.sh`（FAIL=0）。
5. `git grep -n "aether-dns 2026.11.04"` 只剩历史报告与 `dist/` 证据。
6. `git diff --stat main...HEAD` 只含「允许改动」。

## 影响面

- 运行时行为不变，仅版本串变化。
- 消费方风险：proxy ≤0.6.3-r7 按"组件名"取 `2025.08.09` 下限，`1.0.0 < 2025.08.09` 会判过旧并**拒绝启动**。因此 1.0.0 的二进制在 proxy 拆分成按引擎闸门之前**不得装到以 aether-dns 为 DNS 引擎的设备**。本卡只改仓库代码，不安装、不部署。

## 依赖

- 无前置。
- M4-09（打包）依赖本卡；M4-10（CI/发布）依赖 M4-09。
