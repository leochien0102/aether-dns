# M1 任务卡：可跑骨架

> **状态：APPROVED（2026-11-04）。** 所有者已确认 D1–D6；T1.0/T1.1 在 `main`/主检出执行，T1.2 起用 worktree。
> **项目与范围**：本文件的任务卡全部属于 **aether-dns** 仓库（`/workspace/openwrt/aether-dns`）。
> 执行时只在本卡 worktree（`/workspace/openwrt/aether-dns-wt/<卡号>`）中读写；
> **不准修改 aether-proxy、`archive/`、`openwrt-actions/` 或 `/workspace/openwrt` 下的其他仓库**。
> 任务卡要求「参考」其他仓库的文件时，只读不写。执行约定见 [README.md](README.md)。

M1 的目标不是 P0 行为等价，而是**可跑骨架**：`-C` 能读 aether-proxy 的 22 份配置、UDP/TCP 能监听、
一条上游能转发、进程能干净退出；组/列表/tag/nftset/cache/过滤全部留到 M2。
M1 的临时行为（纯转发到第一个 `trust-dns`）**不得**写成 parity `match`，M2 会用真实路由替换。

**卡规则（本文件强制）**：一张卡只有一个目标，目标一句话；验收必须是可执行命令 + 可判定结果；
不写“并/同时/顺带完成”；做不到就停，不扩成第二张卡的内容。

依赖关系：

- T1.0 → T1.1、T1.2、T1.3、T1.6、T1.7
- T1.2 + T1.3 → T1.4 → T1.5
- T1.4 + T1.6 → T1.8 → T1.9（T1.9 还需 T1.5）

T1.2、T1.3、T1.6、T1.7 可在 T1.0 后并行；T1.4 等 T1.2+T1.3；T1.5 等 T1.4。

## T1.2 配置解析（22 份 fixture）

- **单一目标**：把 22 份 `expected/chinadns.conf` 全部解析成有类型的配置；任何未知/非法输入 fail closed。
- **分支**：`m1/config`
- **必读**：[PLAN.md](../../PLAN.md) §2、`aether-proxy/aether-proxy/src/lib/render/chinadns.uc`（只读）、
  22 份 `aether-proxy/tests/fixtures/*/expected/chinadns.conf`（只读）、`spikes/m0-fixtures/coverage.json`。
- **允许改动**：`src/config.rs`、`tests/config.rs`、`tests/data/config/`（如需要）。**不接 `main`**（`-C` 在 T1.4 接）。
- **做什么**
  1. 行格式：UTF-8、空行/`#` 忽略、`key [value]`、不支持行尾注释、带行号错误。
  2. 支持 19 条指令：`bind-addr`、`bind-port`、`china-dns`、`trust-dns`、`ipset-name4`、`ipset-name6`、
     `gfwlist-file`、`chnlist-file`、`default-tag`、`add-taggfw-ip`、`group`、`group-dnl`、`group-upstream`、
     `group-ipset`、`no-ipv6`、`filter-qtype`、`cache`、`cache-stale`、`verdict-cache`。
  3. 上游语法：逗号分隔；`udp://`/`tcp://`/`tls://`、`host@ip#port`、裸 IP；`tls://` 解析保留但启动报“P0-conditional 未实现”。
  4. 校验：IPv4 bind、端口 1–65535（`@proto` 报 P1）、`default-tag ∈ {chn,gfw,none}`、qtype u16、
     cache 非负、group 先声明后配置、`no-ipv6` 仅无规则形式。
  5. 重复语义（与 chinadns-ng 2025.08.09 对齐；已用二进制与上游 `src/opt.zig` 复核）：
     - **追加**：`bind-addr`、`bind-port`、`china-dns`、`trust-dns`、`chnlist-file`、`gfwlist-file`、
       `group-dnl`、`group-upstream`、`no-ipv6`（规则追加）；`filter-qtype` 为并集去重。
     - **最后一条生效**：`default-tag`、`ipset-name4/6`、`add-taggfw-ip`、`cache`、`cache-stale`、
       `verdict-cache`。
     - `group` 每次开始一个新组；`group-ipset` 同组内最后一条生效。
     - **未知指令、缺值、非法值**：带行号报错。
     依据：上游 `opt_bind_addr`/`opt_bind_port`/`opt_china_dns`/`opt_default_tag`/`opt_cache`/`opt_filter_qtype`；
     实测 `-v`：两个 `bind-port` 输出两个 listen addr，两个 `china-dns` 输出两组 upstream，
     两个 `default-tag` 只保留最后，两个 `cache` 只保留 200。**不需要执行者再访问 aether-proxy 之外的源码。**
  6. 22 份 fixture 全过 + ≥8 个非法用例 + 上述重复语义各至少一个用例。
- **不做什么**：不接 `-C`/不写 main；不读列表文件内容；不实现 tag/组/缓存/nftset/过滤；不实现完整 CLI/`config` include/DoT；不改 renderer/fixtures。
- **停点**：fixture 出现未列指令或未覆盖的重复语义；`tls://` 是否 M1 必须支持；group 重名语义——停下询问。

  3. 测试覆盖 `tls://` 解析保留与启动拒绝的判定函数（不经过 main）。
  4. 报告中贴出测试命令与关键输出。

## T1.4 UDP 单上游转发闭环

- **单一目标**：UDP 客户端查询经“第一个 `trust-dns`”拿回正确响应。
- **分支**：`m1/udp-forward`
- **必读**：[M0-REPORT.md](../../M0-REPORT.md) §3.3、§4.4、[PLAN.md](../../PLAN.md) M1、D3/D5。
- **允许改动**：`Cargo.toml`、`Cargo.lock`（加 `tokio` current-thread）、`src/server.rs`、`src/upstream.rs`、
  `src/config.rs`（只加运行读取接口）、`src/main.rs`、`tests/udp_forward.rs`。
- **做什么**
  1. Tokio current-thread；`-C <path>` 读取 T1.2 的配置，非法配置退出非 0；对配置中的每个
     `bind-addr` × `bind-port` 监听 UDP（P0 fixture 只有一个；多值按上游追加语义）；`@proto` 启动报 P1。
  2. 上游：第一个 `trust-dns`；显式 `udp://`/`tcp://` 优先，否则跟客户端协议；`tls://` 启动报错；超时 5 s、1 次。
  3. 转发原始 query（只改 ID）；响应恢复客户端 ID、RA=1；`NOERROR/NXDOMAIN && !TC` 裁 additional；不重编码。
  4. 上游超时/连接错误 → 合成 SERVFAIL（同 question/ID），stderr 记一行。
  5. 集成测试：本地假上游，覆盖 A/AAAA/HTTPS、EDNS 请求、超时。
- **不做什么**：不做 TCP 监听（T1.5）；不做组/列表/tag/`tag:none`/IP 测试/nftset/cache/`no-ipv6`/`filter-qtype`/DoT/多上游竞争；不读列表文件。
- **停点**：D3/D5 已确认；若上游失败语义与基线不一致，或实现发现必须做过滤/多上游，停下询问。
- **验收**
  1. `cargo test --test udp_forward` 退出 0；覆盖 A/AAAA/HTTPS/EDNS/超时 5 个用例。
  2. 用一份 fixture 启动后，用 `dig`（没有 dig 时用测试里的 UDP 客户端）查询 `q1.gfw.example A`，拿到假上游的 A；上游日志显示 ID 已换。
  3. 客户端响应 ID 与查询一致、RA=1、`ar=0`；上游超时用例返回 SERVFAIL。
  4. `./target/debug/aether-dns -C /tmp/bad.conf` 退出非 0 且错误含行号；`-C` 合法 fixture 能启动并监听。
  5. 报告贴出测试与一次手动查询输出。
