时间使用真实单调时钟，从连接前开始测量，包含连接/调度开销。超时断言窗口为 4.8–6 s；
停机使用现有 500 ms 共享预算，进程观测断言为 ≥450 ms 且 <1 s，约 505 ms 包含信号发送与进程轮询开销。
EOF 均要求首次读取直接返回 `Ok(0)`，不把 DNS 数据、连接 reset 或读超时视为通过。

## 测试

| 新增用例 | 断言 |
|---|---|
| complete_frame_roundtrip | 完整帧转发成功；上游 ID 改写、question 不变；客户端 ID 恢复、RA 正常；一帧响应后 EOF，无额外上游查询 |
| idle_timeout_does_not_block_new_connections | 无字节连接约 5 s EOF；等待期间新连接 <1 s 完成正常往返；进程仍存活，无空闲连接引发的上游请求 |
| partial_length_times_out | 仅一个长度字节，约 5 s EOF，无上游请求 |
| partial_body_times_out | 长度完整但正文不完整，约 5 s EOF，无上游请求 |
| length_and_body_share_one_five_second_budget | 第 3 s 才完成长度前缀并发送部分正文，仍在总计约 5 s 关闭，不重置为另一个 5 s |
| shutdown_preempts_timeout_and_keeps_shared_drain_budget | TERM/INT 均在读超时前触发；无字节与半帧连接 EOF；另一个已完整接收、上游不应答的查询使进程使用 500 ms drain 后成功退出，无新增上游请求 |

变异测试：未运行；本卡使用真实 5 s 等待而非替代超时，删除生产超时包装后，空闲/半帧读取不能在断言窗口内得到 EOF，相关用例会失败。
