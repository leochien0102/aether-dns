### 质量门失败传播

在子 shell 中导出 mock `cargo` 函数，分别让 fmt、clippy、test 返回 42；不修改源码或工作区。断言质量门返回 42 且不输出成功标记。

```bash
for stage in fmt clippy test; do
  (
    export FAIL_STAGE="$stage"
    cargo() {
      printf 'mock cargo %s\n' "$*"
      if [ "$1" = "$FAIL_STAGE" ]; then return 42; fi
    }
    export -f cargo
    set +e
    output=$(bash tests/review.sh 2>&1)
    rc=$?
    printf '%s\n' "$output"
    if [ "$rc" -ne 42 ] || [[ "$output" == *'FAIL=0'* ]]; then
      printf 'Unexpected failure propagation: exit=%s\n' "$rc"
      exit 1
    fi
    printf 'PASS: %s failure -> review exit=42, no success marker\n' "$FAIL_STAGE"
  )
done
```

```text

PASS: fmt failure -> review exit=42, no success marker
mock cargo fmt --all -- --check
mock cargo clippy --all-targets -- -D warnings
PASS: clippy failure -> review exit=42, no success marker
mock cargo fmt --all -- --check
mock cargo clippy --all-targets -- -D warnings
mock cargo test --all
PASS: test failure -> review exit=42, no success marker
```
