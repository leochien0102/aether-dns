### CI 权限传递说明

GitHub artifact 传输会规范化文件权限，故 verify 已校验的七文件用内部 `release-assets.tar` 传给 release，再解包后原样复验；没有通过放宽 0755 校验绕过问题。该 tar **仅为跨作业传输容器，不上传 Release**。本地用合成目录模拟这一传输后，`verify-assets.sh` 再验通过，两个裸文件可执行位保留。实际远端 CI 尚未运行；如远端仍不能满足权限断言，须按卡停点交负责人处理。

GitHub Release 本身不保留可执行位，proxy 等消费方下载后必须 `chmod +x`；CI 内部仍按 0755 校验。
