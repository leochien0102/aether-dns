## 测试

| 测试 | 断言重点 |
|---|---|
| slow_first_fast_second | 慢上游在前仍由快上游获胜，慢连接取消 |
| both_legal_first_arrival_not_list_order | 两个都合法时取先到者，慢响应未发送 |
| invalid_first_then_legal | 首个 TCP 短非法响应失败，不阻碍合法响应 |
| wrong_id_first_then_legal | 首个 TCP ID 不匹配，不成为获选结果 |
| all_failed | 连接关闭、非法响应、ID 不匹配均无合法响应时返回错误 |
| silent_peer_does_not_delay_winner | 静默上游不拖慢快响应，观察取消 EOF |
| all_silent_use_five_second_timeout | 两个静默上游并发使用原有 5 s 单次超时，返回 TimedOut 并关闭连接 |
| udp_client_explicit_tcp_and_implicit_udp | UDP 客户端：显式 TCP 优先，隐式 UDP 跟随 |
| tcp_client_explicit_udp_and_implicit_tcp | TCP 客户端：显式 UDP 优先，隐式 TCP 跟随 |
| udp_wrong_id_does_not_win | UDP 错误 ID 被原有 exchange 忽略，另一合法 TCP 响应获胜 |
| empty_group_is_error | 空组立即报错 |

所有 fake upstream 只绑定 `127.0.0.1:0`，不访问外网。正常竞争场景要求在 2 s 内返回；TCP worker 必须在组返回后 1 s 内结束。未进行变异测试。
