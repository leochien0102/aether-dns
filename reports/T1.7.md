### 2. 手动 timeout

在 worktree 的 `target/lifecycle-manual.conf` 中临时写入 localhost、动态空闲非特权端口、`trust-dns udp://127.0.0.1#9`，执行以下命令；完成后删除该临时文件：

```sh
timeout --foreground --preserve-status --signal=TERM --kill-after=1s 0.2s target/debug/aether-dns -C target/lifecycle-manual.conf
echo $?
# 0

timeout --foreground --preserve-status --signal=INT --kill-after=1s 0.2s target/debug/aether-dns -C target/lifecycle-manual.conf
echo $?
# 0
```

两次输出均为：

```text
listening UDP 127.0.0.1:42413
listening TCP 127.0.0.1:42413
shutdown: draining queries (500 ms maximum)
```

`--preserve-status` 保留被测进程的实际退出码，避免 timeout 默认返回 124；`--foreground` 使 timeout 直接向被测进程发送信号，不向整个进程组广播。

如实记录调试现象：最初未加 `--foreground` 时 TERM 返回 0，INT 返回 137 且没有停机日志；加 `env --default-signal=INT` 无变化。最终采用上述直接针对子进程的手动验收命令，TERM/INT 均返回 0；系统 kill 的 TERM/INT 集成测试也全部通过。未据此改动卡外进程组或监督协议。
