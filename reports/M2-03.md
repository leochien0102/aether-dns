```bash
export PATH="$PATH:/usr/sbin:/sbin"
unshare -Urn -- bash -euo pipefail -c '
    nft -f - <<EOF
add table inet m2nft
add set inet m2nft addresses { type ipv4_addr; flags interval; auto-merge; elements = { 1.2.3.0/24 }; }
EOF
    NFT_TEST=1 cargo test --test nftset -- --nocapture
```

## 测试

- 解析：ip/ip6/inet 与错误 family、缺字段、空字段、多字段、嵌入 NUL。
- 重试：确定性注入 EEXIST，断言第二次成功；连续 EEXIST 断言恰好两次调用并向调用者保留 errno。内核 EEXIST 由真实 interval 内添加触发；没有用时序竞态冒充确定性重试测试。
- 内核：GETSETELEM 的区间内命中/区间外未命中；batch begin/end 与 NEWSETELEM ACK；三个相邻 IP 的 begin/end 与下一地址未命中；精确重复幂等；区间内 EEXIST 导致同批新 IP 回滚；test-then-add 跳过既有区间并去重输入；缺失集合写入保留 ENOENT；同一 socket 删表、重建后恢复；父 netns 上无管理权限的子 userns 查询和批量写入保留 EPERM。
- 未做变异测试。

## 偏差与待定

- 无范围偏差，无 TODO(design)，未触发停点。实测内核行为与 M0 一致。
- 遵循 IMP-004，成员查询的 ENOENT 映射为 false（内核不区分缺失元素/缺失集合）；写入不存在集合返回可识别 ENOENT，EPERM 原样返回。日志由未来调用者负责，本卡未接 server。
- 不修改入口或新增 lib.rs，模块由本卡集成测试通过 path 编译；后续接入不在本卡范围。
- 仅提供 IPv4 数据路径；ip6 family 语法可解析，不扩展 IPv6 业务。
- 属性超过 netlink u16 长度时返回 InvalidInput，不截断；接收有超时和截断检查。
